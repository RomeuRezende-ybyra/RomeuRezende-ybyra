## 🛠️ How I work

I build with **Spec-Driven Development** — every feature is specified before it's implemented, so decisions are documented and any competent team can pick the code up and extend it. The `specs/` folder in the [Spravio repo](https://github.com/RomeuRezende-ybyra/spravio-showcase) shows this in practice.

I care about the things that make SaaS survive contact with real users: **multi-tenant data isolation, security and LGPD/GDPR, clean architecture, and documented decisions.**
